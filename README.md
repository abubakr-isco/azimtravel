# Azim Travel CRM

CRM для заявок, транспорта и учёта водителей. Начальные данные — из Excel «Графики июль–декабрь 2026».

- **Без сервера**: откройте `index.html` в браузере. Данные хранятся в этом браузере (только на этом компьютере).
- **С сервером**: данные общие для всех сотрудников. Что должен уметь сервер — в [API.md](API.md).

## Разделы

- **Обзор** — группы в пути сегодня, заезды на неделю, трансферы на сегодня/завтра, загрузка автопарка, выручка по месяцам.
- **Заявки** — таблица как лист «Заявки» в Excel (слева данные заявки, справа программа маршрута по дням: дата, маршрут, услуги со временем, стоимость) или компактный список; поиск и фильтры (заказчик, месяц, статус, оплата), карточка заявки с программой по дням, оплатами и историей, создание и редактирование, аннуляция, печать программы, выгрузка в CSV.
- **График заявок** — одна лента по дням без деления на месяцы (как лист «График заявок»): минимум июль–декабрь, расширяется, если есть заявки раньше или позже; при открытии показывает сегодняшний день, кнопки месяцев и «Сегодня» прокручивают к нужной дате. В клетке дня — маршрут целиком («Таш-Сам») и услуги со временем (вс аэ, пр ж/в, экя…), внизу — цена за день (так же в графике транспорта). Цвета берутся из набора 9 хорошо различимых (в том числе при нарушениях цветового зрения), соседние строки всегда разного цвета; цвет можно сменить в карточке заявки, аннулированные — серые. Любую клетку дня можно изменить: клик открывает маршрут, услуги, стоимость и цвет этой клетки (стрелками — к соседнему дню); так же работают клетки программы в таблице «Заявки».
- **Транспорт** — автопарк, загрузка, график по дням одной лентой (как лист «График транспортный»), выплаты перевозчикам. У машин цвета из того же набора, соседние строки разного цвета: полоски в графике и метки в списках; цвет можно сменить в карточке машины. Частный транспорт — серый. Кнопка «Добавить авто» в шапке добавляет свою машину или частного перевозчика, в карточке машины — «Изменить». В графике по дням клик по клетке меняет рейс, по пустой клетке — добавляет новый.
- **Учёт водителей** — отдельный раздел в меню: книга водителя как в Excel «Asiastar 30 277 SBA» для каждой своей машины. Сверху итоговый отчёт по всем водителям (приход, расходы водителей, машина, командировочные, НДФЛ, топливо, запчасти, прибыль; фильтр по марке и месяцу), клик по строке или кнопка «Учёт водителя» в карточке машины открывает книгу с листами (повторный клик по разделу в меню возвращает к списку):
  - *Маршрутные листы* — подряд идущие дни графика машины; по дням проживание, питание, доп. расходы машины (сум), командировочные и цена услуг (USD), компания; шапка листа (водители, группа, туристы, курс), «Дано на расходы», чистый доход, печать листа. Суммы вводятся прямо в таблицу (Enter — строка ниже), «Заполнить по норме» подставляет нормы из Настроек в пустые клетки (проживание — только если ночёвка не в Самарканде), ножницы у дня начинают с него новый лист.
  - *Итоговый отчёт* — все маршрутные листы с расходами и чистым доходом.
  - *Топливо* — заправки: счётчик, пробег, литры, цена, сумма в сумах и USD, расход на 100 км.
  - *Запчасти* — наименование, количество, цена, сумма в сумах и USD.
  - *Зарплата и ком.* — зарплата на карту, НДФЛ, командировочные наличными по месяцам.
  - *Отчёт · прибыль* — приход минус все расходы и остаток командировочных к выплате.
- **Взаиморасчёты** — с заказчиками (USD и сумы перечислением с НДС) и с перевозчиками, акт сверки для печати.
- **Заказчики** — карточки заказчиков со статистикой.
- **Настройки** — курс и НДС по умолчанию, нормы водителей (питание, проживание, командировочные), где хранятся данные, заявки в CSV, резервная копия и восстановление из неё, замена всех данных данными из Excel, справочник сокращений.

Период графиков и фильтров по месяцам не привязан к 2026 году: он начинается с июля 2026 (или с самой ранней даты в данных) и растёт вместе с данными и текущим месяцем.

## Где хранятся данные

В левом нижнем углу видно, где сейчас данные и дошли ли правки до сервера.

- `js/config.js`, `api: ""` — данные в `localStorage` браузера. Каждая правка сохраняется сразу.
- `api: "/api"` — данные на сервере. Правки уходят через полсекунды. Если связи нет, CRM повторяет попытку и не даёт закрыть вкладку, пока правки не сохранены. Правки других сотрудников подтягиваются раз в 30 секунд. Если двое одновременно изменили разные заявки, сохраняются обе правки; если одну и ту же — остаётся сохранённая первой, второй сотрудник видит предупреждение.
- Когда к серверу подключаются впервые и на нём пусто, CRM отправляет туда данные из этого браузера, а если их нет — данные из Excel.

## Выкладка на сервер

```bash
python3 tools/build.py --api /api            # первый запуск: с данными из Excel
python3 tools/build.py --api /api --no-seed  # когда база уже на сервере
```

Сборка кладёт в `dist/` только файлы сайта (без Excel, видео и скриптов) и добавляет к ссылкам на css/js `?v=<хеш>`, чтобы после обновления браузеры не брали старые файлы. Содержимое `dist/` и выкладывается на сервер. Сайт и API должны быть закрыты входом — см. [API.md](API.md).

## Обновить данные из Excel

```bash
pip install openpyxl
python3 tools/excel_to_data.py "Графики_июль_декабрь_2026_г —_копия.xlsx"
```

Скрипт перезаписывает `js/data.js`. Уже сохранённые данные CRM он не трогает: чтобы заменить их файлом, нажмите в Настройках «Заменить всё данными из Excel» (перед этим скачайте резервную копию).

Что скрипт делает с особыми случаями в файле:

- туристы, записанные как «12+1» или «15/22», сохраняются как в Excel; для сумм берётся 13 и 15;
- если Excel превратил запись туристов в дату (заявка №89: 07.07), она сохраняется как «7/7» — проверьте;
- заявка №580 (CATS, март 2024, без программы) пропускается как пустая строка-образец;
- программа заявки берётся с листа «Заявки». Лист «График заявок» в файле заполнен отдельно и местами с ним расходится; он не импортируется.

## Структура

```
index.html             — разметка
css/style.css          — стили (светлая и тёмная тема)
js/config.js           — адрес API сервера (пусто — хранение в браузере)
js/app.js              — логика CRM
js/data.js             — начальные данные из Excel (генерируется скриптом)
tools/excel_to_data.py — импорт из Excel
tools/build.py         — сборка для сервера в dist/
API.md                 — что должен уметь сервер
```
