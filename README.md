# Azim Travel CRM — демо

Демо CRM-системы на данных из Excel «Графики июль–декабрь 2026».
Сервер не нужен: откройте `index.html` в браузере.

## Разделы

- **Обзор** — группы в пути сегодня, заезды на неделю, трансферы на сегодня/завтра, загрузка автопарка, выручка по месяцам.
- **Заявки** — таблица как лист «Заявки» в Excel (слева данные заявки, справа программа маршрута по дням: дата, маршрут, услуги со временем, стоимость) или компактный список; поиск и фильтры (заказчик, месяц, статус, оплата), карточка заявки с программой по дням, оплатами и историей, создание и редактирование, аннуляция, печать программы, выгрузка в CSV.
- **График заявок** — одна лента по дням без деления на месяцы (как лист «График заявок»): минимум июль–декабрь, расширяется, если есть заявки раньше или позже; при открытии показывает сегодняшний день, кнопки месяцев и «Сегодня» прокручивают к нужной дате. В клетке дня — маршрут целиком («Таш-Сам») и услуги со временем (вс аэ, пр ж/в, экя…). Цвета берутся из набора 9 хорошо различимых (в том числе при нарушениях цветового зрения), соседние строки всегда разного цвета; цвет можно сменить в карточке заявки, аннулированные — серые.
- **Транспорт** — автопарк, загрузка, график по дням одной лентой (как лист «График транспортный»), выплаты перевозчикам. У машин цвета из того же набора, соседние строки разного цвета: полоски в графике и метки в списках; цвет можно сменить в карточке машины. Частный транспорт — серый.
- **Взаиморасчёты** — с заказчиками (USD и сумы перечислением с НДС) и с перевозчиками, акт сверки для печати.
- **Заказчики** — карточки заказчиков со статистикой.
- **Настройки** — курс и НДС по умолчанию, экспорт, сброс данных, справочник сокращений.

Изменения сохраняются в `localStorage` браузера (кнопка «Сбросить демо-данные» возвращает данные из Excel).

## Обновить данные из Excel

```bash
pip install openpyxl
python3 tools/excel_to_data.py "Графики_июль_декабрь_2026_г —_копия.xlsx"
```

Скрипт перезаписывает `js/data.js`.

## Структура

```
index.html            — разметка
css/style.css         — стили (светлая и тёмная тема)
js/app.js             — логика CRM
js/data.js            — данные (генерируется скриптом)
tools/excel_to_data.py — импорт из Excel
```
